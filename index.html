关于我

About Me · AI视觉设计师 × AI编程实践者

从AI工具使用者，到AI视觉创作者，再到AI编程实践者

我是李大海，最初像许多设计同学一样，用Midjourney和可灵生成视觉素材——但我不满足于"生成即交付"。我开始追问：AI视觉如何真正落地到产品和场景中？这个追问带我走进了Blender三维制作，又带我走进了AI辅助编程的世界。

在零编程基础的情况下，我通过AI协作从零学会了HTML/CSS/JavaScript，独立搭建了你现在看到的这个作品集网站——包括动态壁纸预览、Prompt卡片生成器、交互式工作流节点图和色彩析出工具等交互应用。更进一步，我使用 Next.js + TypeScript + DeepSeek API 独立开发了「AI 创意引擎」全栈 Web 应用，实现从创意输入到专业提示词/脚本/方案的全自动生成管线。这不仅是技术能力的证明，更代表我作为"AI Native创作者"的工作方式：用AI拓展边界，用编程实现想法，用设计审美把关输出。
